🔗 Topologi Jaringan

Topologi jaringan adalah konfigurasi fisik maupun logis yang menggambarkan bagaimana perangkat atau node dalam jaringan saling terhubung.

Topologi Fisik

Menggambarkan struktur fisik jaringan seperti kabel, perangkat jaringan, dan koneksi.

Topologi Logika

Menggambarkan bagaimana data atau sinyal mengalir antarperangkat.

1. Topologi Bus

Semua komputer terhubung pada satu kabel utama yang disebut backbone.

PC 1 ↔ PC 2 ↔ PC 3 ↔ PC 4

Kelebihan

  • Penggunaan kabel relatif sedikit.
  • Biaya relatif efektif.
  • Cocok untuk jaringan kecil.
  • Penambahan perangkat relatif mudah.

Kekurangan

  • Kurang cocok untuk jaringan besar.
  • Gangguan backbone dapat mengganggu jaringan.
  • Kinerja dapat menurun jika node bertambah.

2. Topologi Ring

Setiap perangkat terhubung membentuk lingkaran. Data diteruskan dari satu node ke node berikutnya.

A → B → C → D ↩

Kelebihan

  • Aliran data teratur.
  • Tidak membutuhkan node pusat.
  • Instalasi relatif mudah.

Kekurangan

  • Kerusakan kabel dapat mengganggu jaringan.
  • Delay dapat meningkat ketika jumlah node bertambah.

3. Topologi Dual-Ring

Pengembangan dari ring yang menggunakan dua jalur lingkaran untuk meningkatkan keandalan jaringan.

Kelebihan

  • Memiliki jalur alternatif.
  • Keandalan dapat lebih baik.
  • Aliran data lebih teratur.

Kekurangan

  • Konfigurasi lebih kompleks.
  • Biaya dapat lebih tinggi.

4. Topologi Star

Setiap perangkat terhubung langsung ke perangkat pusat seperti switch atau hub.

PC 1 ↘ 🔵 SWITCH ↙ PC 2 PC 3 ↗ PC 4

Kelebihan

  • Mudah dikembangkan.
  • Mudah melakukan troubleshooting.
  • Kerusakan satu kabel tidak langsung memutus node lain.
  • Penambahan perangkat relatif mudah.

Kekurangan

  • Membutuhkan kabel lebih banyak.
  • Membutuhkan perangkat pusat.
  • Jika perangkat pusat gagal, jaringan dapat terganggu.

5. Topologi Mesh

Setiap node memiliki koneksi langsung dengan node lain. Pada mesh penuh, setiap perangkat terhubung dengan semua perangkat lainnya.

Routing

Data dapat menentukan jalur tertentu menuju tujuan dan menghindari jalur yang mengalami masalah.

Flooding

Data diteruskan ke banyak atau semua node. Metode ini dapat meningkatkan kemungkinan data mencapai tujuan tetapi juga meningkatkan beban jaringan.

Kelebihan

  • Banyak jalur alternatif.
  • Keandalan tinggi.
  • Gangguan satu jalur tidak selalu menghentikan komunikasi.

Kekurangan

  • Membutuhkan banyak kabel.
  • Biaya tinggi.
  • Konfigurasi kompleks.

6. Topologi Hybrid

Topologi hybrid merupakan gabungan dua atau lebih jenis topologi.

Kelebihan

  • Fleksibel.
  • Dapat disesuaikan dengan kebutuhan.
  • Dapat dikembangkan.

Kekurangan

  • Konfigurasi lebih kompleks.
  • Biaya dapat lebih mahal.

7. Topologi Tree

Topologi tree menggunakan struktur hierarki seperti pohon dan menggabungkan karakteristik star dan bus.

ROOT ↓ CABANG ↓ NODE

🧭 Pemilihan Topologi

Pemilihan topologi harus disesuaikan dengan kebutuhan jaringan.

Hal yang harus dipertimbangkan

  1. Panjang kabel.
  2. Jenis kabel.
  3. Biaya.
  4. Jumlah perangkat.
  5. Kemampuan jaringan berkembang.
  6. Kemudahan pemeliharaan.

📡 Protokol Transport

TCP

TCP atau Transmission Control Protocol adalah protokol connection-oriented. TCP menggunakan nomor urut dan acknowledgement untuk membantu memastikan data diterima dengan benar dan dapat dikirim ulang jika diperlukan.

UDP

UDP atau User Datagram Protocol merupakan protokol connectionless. UDP lebih sederhana karena tidak melakukan proses pembentukan koneksi seperti TCP.

SCTP

SCTP atau Stream Control Transmission Protocol mendukung komunikasi dengan beberapa stream data dan memiliki mekanisme yang berbeda dari TCP maupun UDP.

🔌 Connection-Oriented vs Connectionless

Aspek Connection-Oriented Connectionless
Koneksi Membangun koneksi terlebih dahulu. Tidak perlu membangun koneksi terlebih dahulu.
Keandalan Dapat menggunakan acknowledgement dan retransmission. Tidak menyediakan mekanisme keandalan seperti TCP.

🌍 Internet Layer

IP

Internet Protocol digunakan untuk pengalamatan logis dan pengiriman paket antarjaringan.

ARP

Address Resolution Protocol digunakan untuk mengetahui alamat MAC berdasarkan alamat IP yang diketahui.

ICMP

Internet Control Message Protocol digunakan untuk pesan kontrol dan informasi mengenai kondisi jaringan.

🧰 Application Layer

  • HTTP / HTTPS → komunikasi web.
  • FTP → transfer file.
  • POP3 → pengambilan email.
  • SMTP → pengiriman email.
  • SNMP → pengelolaan perangkat jaringan.
